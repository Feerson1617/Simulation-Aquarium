# Fotobasierter Modellversuch

Die Vergleichsbilder sind echte Chromium/WebGL-Aufnahmen des bestehenden Spiels im Profil Ultra (keine Bildgenerierung). Die drei TripoSR-Modelle wurden dafür vorübergehend als echte Art-GLBs geladen; die Produktionsdateien wurden anschließend bytegenau wiederhergestellt.

**Zwischenergebnis:** Guppy und Metallpanzerwels erfüllen die Qualitätsanforderungen nicht (verdickte Flossen bzw. verschmolzene Anatomie). Beim ersten Anubias-Versuch erfasste die automatische Freistellung das Beschriftungsschild. Die Eingabe wird vor der abschließenden Bewertung geprüft. Es gibt keine Freigabe zur Übertragung auf weitere Arten.

Bilder: `comparison/`. Messwerte: `runtime-review.json`. Lauf: https://github.com/Feerson1617/Simulation-Aquarium/actions/runs/39272907955
