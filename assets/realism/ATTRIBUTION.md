# Original hardscape assets

All 22 GLB files (11 catalog entries × desktop/mobile LOD) in this directory were generated locally for Simulation-Aquarium with `tools/realism/build_hardscape.py`, using Blender 4.3.2. No downloaded geometry, textures, add-ons, accounts or online generation services were used.

These newly authored GLB meshes and their generated vertex colors are dedicated to the public domain under **CC0 1.0 Universal**: https://creativecommons.org/publicdomain/zero/1.0/ . This dedication applies only to these original GLBs. Existing fish, photographs, libraries and project source retain their own licenses; in particular the existing BlueMesh Betta remains CC BY 4.0.

Procedural surface detail is generated locally by `realism-materials.mjs`; no externally hosted images are required. Units/pivots use the existing aquarium coordinate system, with the model base at y=0 and a footprint contained by the existing placement model. Both LODs have identical nominal bounds. A denser mesh does not establish photographic realism; see the catalog review matrix.
